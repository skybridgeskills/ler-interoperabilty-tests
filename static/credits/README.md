# Credit logos

Logos for the About page's **Built by** rows (`src/lib/pages/about/credits.ts`). One file per
organisation, SVG preferred, named after the organisation (`skybridge-skills.svg`). Each renders
on a uniform white rounded tile in both themes, so supply the version made for a light
background — no dark-mode variants. Set the row's `logo` to `/credits/<file>` once the file is
here; a row without one renders name and role only.
